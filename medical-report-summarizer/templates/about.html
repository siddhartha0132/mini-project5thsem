How it works

Each report passes through an NLP pipeline of eight stages.

  1. UploadText, PDF or a scanned image of the report.
  2. Text extractionPyMuPDF reads PDFs; Tesseract OCR reads scans after grayscale, contrast and threshold clean-up.
  3. Pre-processingRemoves headers and page numbers, expands abbreviations (HTN → hypertension), detects sections and splits sentences.
  4. Medical NERA medical dictionary with negation detection, plus an optional BERT model (d4data/biomedical-ner-all), tags diseases, symptoms, drugs and procedures. Lab values are compared with reference ranges.
  5. SummarizationExtractive: TextRank (TF-IDF + cosine similarity + PageRank) with medical boosts. Abstractive: a BART transformer ({{ model.split('/')[-1] }}). Hybrid: TextRank selects, BART rewrites.
  6. Fact checkEvery number and medical term in the summary must exist in the source; coverage of key facts is measured.
  7. Doctor summaryThe clinical summary with abnormal values highlighted.
  8. Patient summaryGlossary-based simplification into plain language, with explanations of abnormal results. Readability is measured with the Flesch Reading Ease score.

TextRank scoring

WS(Vi) = (1 − d) + d · Σj [ wji / Σk wjk ] · WS(Vj)

d = 0.85 (damping factor); w = cosine similarity between TF-IDF vectors of two sentences. The final score is multiplied by a section weight (Diagnosis and Impression count most), an entity boost and an abnormal-lab boost.

Evaluation

Run python scripts/evaluate.py to score all methods with ROUGE-1, ROUGE-2 and ROUGE-L against the reference summaries in data/references.json.
